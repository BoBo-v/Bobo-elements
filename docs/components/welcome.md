# Welcome 欢迎页

用于 AI 对话空状态或开屏引导，支持图标、标题、描述及推荐词插槽组合。

## API

| 属性名 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| title | 欢迎标题 | `string` | — |
| description | 欢迎描述 | `string` | — |
| icon | 图标名称 | `string` | `'sparkles'` |
| variant | 外观样式 | `'borderless' \| 'filled'` | `'borderless'` |
| align | 对齐方式 | `'left' \| 'center'` | `'left'` |
